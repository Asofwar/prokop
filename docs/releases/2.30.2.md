## Smart Detect работает с несколькими Bootstrap DNS

Срочное исправление. Если в настройках указано два и больше Bootstrap DNS-сервера, Smart Detect на любую проверку отвечал «Первый Bootstrap DNS-сервер должен быть IP-адресом», хотя все серверы были IP-адресами. Обновление ставится поверх, настройки не меняются, ничего делать вручную не нужно.

## Что изменилось

- **Smart Detect берёт тот же Bootstrap DNS, что и сам Prokop.** Раньше проверка читала список Bootstrap DNS как одну строку, и при нескольких серверах получалось «77.88.8.8 8.8.8.8», что не является адресом. Теперь проверка использует Bootstrap DNS из работающей конфигурации sing-box, то есть сервер, который сейчас выбран переключением DNS. Если его там нет, берётся активный сервер из настроек. Порт, если он указан (например `8.8.8.8:5353`), тоже учитывается; раньше он терялся.

## Что проверено

- PASS: автоматические тесты бэкенда (полный прогон, без root). Новые проверки в `tests/fork_experiments.sh`: выбор Bootstrap DNS из работающей конфигурации, два сервера в настройках, сервер с портом, значение по умолчанию, отказ на имени хоста вместо IP.
