## Smart Detect проверяет выходы через VPN-интерфейс

Срочное исправление. Для выхода через VPN-интерфейс (например AWG) Smart Detect отвечал «Установленный sing-box отклонил конфигурацию проверки». Обновление ставится поверх, настройки не меняются, ничего делать вручную не нужно.

## Что изменилось

- **Конфигурация проверки забирает DNS выбранного выхода.** У выхода через интерфейс нет своего сервера, но есть свой DNS-сервер, через который он разрешает имена. Проверка копировала выход без этого DNS-сервера, и sing-box отклонял конфигурацию («domain resolver not found»). Теперь такой DNS-сервер копируется вместе с выходом, а его ссылка на Bootstrap DNS заменяется на DNS проверки.
- **Причина отказа sing-box сохраняется.** Если sing-box всё же отклонит конфигурацию проверки, его сообщение остаётся в `/var/run/prokop/smart-detect/check.log` (только в памяти, доступ только root).

## Что проверено

- PASS: автоматические тесты бэкенда (полный прогон, без root). Новая проверка в `tests/fork_experiments.sh`: DNS-сервер выхода через интерфейс копируется вместе с ним.
- PASS: конфигурация проверки построена для каждого выхода из всех тестовых конфигураций Prokop и прогнана через `sing-box check` 1.14.0. Ошибок «domain resolver not found» больше нет. Остальные отказы относятся к возможностям, которых нет в официальной сборке sing-box (xhttp, uTLS, поля расширенной сборки), и так же отклоняются в основной конфигурации.
- NOT TESTED: на роутере. Что у тебя причина именно эта, не подтверждено: точный текст ошибки с роутера не получен.
