## Prokop — новое имя и свой канал релизов

- **Этот форк Forkop теперь называется Prokop.** Линия проекта: Podkop → Podkop Plus → Forkop (ushan0v) → Forkop (slayer326) → Prokop. Код тот же, меняются имена: пакеты `prokop`, `luci-app-prokop` и `luci-i18n-prokop-ru`, настройки в `/etc/config/prokop`, команда `prokop`, страница **Службы → Prokop** в LuCI.
- **Свой канал релизов.** Установщик и встроенное обновление берут Prokop из `https://asofwar.github.io/prokop`, а если канал недоступен — из GitHub Releases репозитория [Asofwar/prokop](https://github.com/Asofwar/prokop). Репозиторий раньше назывался `Asofwar/forkop`; прежний адрес канала `https://asofwar.github.io/forkop` больше не работает.
- **Нумерация начинается с 2.0.0**, то есть с номера больше любой версии Forkop 1.0.x, поэтому переход не выглядит как откат.

## Переход с Forkop

Перейти на Prokop обычным обновлением из LuCI нельзя: встроенное обновление Forkop ищет пакеты `forkop`. Переход делает установщик. На роутере с Forkop любой версии 1.0.x, и со сборкой slayer326/forkop, и с прежними сборками этого форка, выполните:

```sh
wget -qO- https://asofwar.github.io/prokop/install.sh | sh
```

Установщик найдёт Forkop и спросит подтверждение. Без терминала (из скрипта, через `ssh router 'команда'`) нужен флаг: `| sh -s -- --confirm-legacy-migration`. Без флага установщик ничего не меняет.

- **Сохраняется всё нужное:** настройки, подключения, подписки, списки и наборы правил, резервные копии конфигурации, установленный sing-box, своё зеркало, права пользователей LuCI и настройки страниц в браузере. Кэш подписок Forkop не переносится: подписки скачиваются заново.
- **Состояние службы сохраняется.** Если Forkop был включён и работал, Prokop включится и запустится; если был выключен, Prokop тоже останется выключенным.
- **Kill-switch остаётся закрытым всё время перехода.** Клиенты защищённых секций на время переключения остаются без интернета, а не уходят напрямую. Правила Forkop снимаются только после того, как Prokop применит свои. Остальные подключения ненадолго прерываются, пока sing-box перезапускается уже под Prokop.
- **Ошибка не оставляет роутер без управления.** Если переход сорвался до удаления Forkop, всё откатывается и Forkop остаётся как был. Если после удаления, настройки Prokop и резервные копии остаются на месте, служба выключена, а установщик печатает пути к копиям и следующие шаги. Прерванный переход продолжается повторным запуском той же команды.
- Старый адрес страницы LuCI `admin/services/forkop` после перехода не открывается.

Переход с Podkop и Podkop Plus работает как раньше. На роутерах, где Forkop не стоял, ничего из этого не выполняется.

## Зеркало зависимостей — только по желанию

По умолчанию зеркала нет: пакеты OpenWrt идут из официальных фидов, списки, наборы правил, sing-box-extended и Zapret-Manager — из исходных репозиториев. Своё зеркало включается явно:

```sh
wget -qO- https://asofwar.github.io/prokop/install.sh | sh -s -- --mirror https://mirror.example.org
```

Если в Forkop было задано своё зеркало, оно сохраняется. Бывшие зеркала upstream (`mirror.infotechtg.ru`, `mirror.51343.ru`) выключаются, а адреса списков на них переводятся на прямые источники.

## Безопасность

- **Чужой APK-ключ и чужой фид пакетов не принимаются.** Ни установщик, ни пакеты не кладут ключ зеркала в `/etc/apk/keys` и не добавляют фид `forkop.list`, а найденные `/etc/apk/keys/forkop-mirror.pem` и `/etc/apk/repositories.d/forkop.list` удаляют. `apk` доверяет каждому ключу для любого репозитория, так что такой ключ позволил бы владельцу зеркала подписать любой пакет, в том числе пакет из официального фида OpenWrt.
- **Каждый пакет сверяется с SHA-256** из метаданных канала, а при резерве через GitHub Releases — с `digest`, который GitHub указывает для файла. Канал публикуется только целиком: если в самом новом релизе не хватает пакета или не совпала сумма, остаётся предыдущая версия канала.

## Установка

```sh
wget -qO- https://asofwar.github.io/prokop/install.sh | sh
```

Если `asofwar.github.io` недоступен:

```sh
wget -qO- https://github.com/Asofwar/prokop/releases/latest/download/install.sh | sh
```

Поддерживаются OpenWrt 24.10 (`opkg`) и 25.12+ (`apk`). Полный список параметров — `| sh -s -- --help`.
